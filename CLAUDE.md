# CLAUDE.md

## How to reply

- Write replies conversationally, in plain spoken English that sounds natural
  read aloud. The owner often plays replies back as audio, so avoid tables,
  symbols and jargon in the reply itself.
- Keep replies short. Go long only when the task really needs an exhaustive
  answer.

## Repo housekeeping

- Suggest GitHub and git best practices proactively: a separate branch per
  topic, when to open or split a pull request, release and version hygiene,
  CI checks, cleanup. The owner won't think to ask for these, so offer them
  in a sentence when they apply, then do them once agreed.
