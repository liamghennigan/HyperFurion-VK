01 · molten dictation

Words land while you speak.

Each word stays molten for 1.5 seconds — long enough to repair itself in place — then freezes and is never touched again. Say “scratch that” to take a sentence back.

02 · registers

The same words, typed the way the app wants.

It probes the focused app and picks a register: prose gets capitals and punctuation, a terminal gets digits and no caps, python and shell compile speech into code.

Install HyperFurion VK.

Download it and run it as yourself — no sudo, no administrator. It installs for your user, then walks you through the settings: speech provider, hotkey, language, Kai. Running a local llama-server? Setup finds it and offers its model as your default.

Download for Linux Download for Windows

HyperFurion-VK-Setup.run · run it as yourself, no sudo for the app

Free and open source. Every feature works with your own provider key or a local model; nothing is paywalled. macOS is in beta — install from a checkout.

What gets installed
  • Linux: a Python package in ~/.local/share/voice-keyboard-venv, the voice-keyboard CLI, a systemd user service, a GNOME Shell overlay extension (45–50), and the uinput rule for the virtual keyboard. Your password is asked once, for the audio libraries and keyboard access.
  • Windows 10/11: a tray app with a native overlay and the Kai orb. Installs Python for you if needed. Press CtrlAltV in any app.
  • Config: ~/.config/voice-keyboard/config.toml, mode 600. Audio is held in memory while transcribed, never written to disk. Password fields always force the verbatim register and are never logged.

the full board

Everything a keyboard does, spoken.

edit

Spoken edits

“Scratch that”, “new line”, “period”, “open quote” — a real edit grammar, parsed before anything is typed. Say literal to type the next word as-is.

numbers

Digits where they belong

“Twenty three” becomes 23 in a terminal and stays words in prose. “One two seven” is 127. Decimals too.

rewrite

“VK, make that formal”

The wake word sends what you just said through your language model and repairs it on screen, in place. Hold it for approval if you like.

assistant

Kai, in the keyboard

Hold Right Ctrl and ask. In a terminal Kai drafts the command and stops. Anywhere else it answers aloud. A one-gigabyte local model is enough.

read

Read anything aloud

Select text in any app and the keyboard speaks it — xAI, OpenAI, ElevenLabs, or a local voice.

recall

An opt-in memory

A local ledger of what you dictated: list it, re-type it, search it. It also mines your corrections to learn your vocabulary. Off until you turn it on.

the edges

Honest about the edges.

  • Linux and Windows are first-class. macOS is in beta, installed from a checkout. iOS cannot host a system-wide keyboard like this.
  • Live, molten typing needs a streaming speech provider. Non-streaming providers type when you stop talking.
  • Repairs assume nothing else edits the field while you dictate. Click elsewhere mid-sentence and the text lands on your clipboard instead.
  • A spoken “new line” in prose types a line break. The Enter refusal applies where it matters: command drafting and Kai. Full list on GitHub →
